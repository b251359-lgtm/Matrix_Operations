# Matrix Operations
Built a Matrix Operations Library in C++ supporting dynamic matrix operations including addition, multiplication, transpose, and recursive determinant computation for NxN matrices using vector-based implementations.


Features Now Included
Dynamic matrix size
Matrix addition
Matrix multiplication
Matrix transpose
Determinant of any NxN matrix
Recursive determinant calculation
User-defined values


Concepts Used
This project demonstrates:
Recursion
Dynamic memory using vectors
Matrix algebra
Cofactor expansion
Modular programming
Nested loops
Functions
